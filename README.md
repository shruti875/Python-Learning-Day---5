# Stage 6: File Handling & Error Handling in Python 🐍

## 📌 Overview
Stage 6 focuses on file handling, data persistence, JSON operations, and exception handling in Python. These concepts help programs store information permanently, retrieve saved data, update records, and handle errors safely.

## 🎯 Topics Covered
- File handling: reading (`r`), writing (`w`), and appending (`a`)
- Opening and closing files using `open()` and `with`
- Reading from and writing to text files
- JSON file handling using Python's `json` module
- Using `json.load()` and `json.dump()`
- Exception handling with `try` and `except`
- Handling `FileNotFoundError`, `ValueError`, and `json.JSONDecodeError`
- Saving and updating records
- Data persistence
- Working with functions, lists, and dictionaries

## 🛠️ Projects Completed

### 1. Notes Application 📝
A simple Python application that allows users to create and save notes in a file and read them later.

**Features:**
- Write and save notes
- Read previously saved notes
- Store information in a file
- Preserve notes after restarting the program
- Handle missing files when no notes have been saved

**Concepts Used:** File handling, functions, loops, and exception handling.

### 2. Contact Book 📒
A Python application that manages contact information and stores it in a JSON file.

**Features:**
- Add new contacts
- View all saved contacts
- Search for contacts by name
- Update contact details
- Delete contacts
- Store phone numbers and email addresses
- Save and load contacts using JSON
- Handle missing files and invalid JSON data

**Concepts Used:** JSON, dictionaries, functions, loops, file handling, and exception handling.

### 3. Student Records System 🎓
A Python application that stores and manages student records using a JSON file.

**Features:**
- Add student records
- View all students
- Search for students by ID
- Update student names and marks
- Validate marks and user input
- Save records in `students.json`
- Load saved records when the program restarts

**Concepts Used:** JSON, dictionaries, lists, functions, file handling, and error handling.
